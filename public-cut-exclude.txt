# Path exclusion manifest — what must never be published.
#
# ORIGINAL PURPOSE (2026-07-15 to 2026-09-09). This repository used to be a
# periodic, hand-scrubbed cut of a private one, and this file was the scrub
# list: `scripts/public-cut.sh` read it, removed every path named here, and
# `tests/lint-public-cut-exclude.py` asserted each pattern still matched
# something. Both of those lived in the private repo. The cut workflow retired
# on 2026-09-09 when development moved here, so the script was removed rather
# than left in place calling a gate that this repository, by design, does not
# ship.
#
# CURRENT PURPOSE. This file is still load-bearing, for a different job: it
# defines the "public surface" that two gates scan.
#
#   tests/lint-brand-free.py         — no private-org reference in a pull path
#   tests/lint-counterparty-names.py — no counterparty identity, ever
#
# Both compute their scope as `git ls-files` MINUS the paths below. In this
# repository those paths are already absent, so the surface is the whole tree —
# which is the correct answer here, and keeps one definition of "public
# surface" shared by both gates rather than two that can drift apart.
#
# The entries below are kept because they document what must never appear here,
# and because a path that ever reappears must be excluded again deliberately.
#
# Format: one path per line, matched against `git ls-files` output.
#   - a line ending in `/` excludes that directory and everything under it
#   - any other line excludes exactly that path
#   - `#` starts a comment; blank lines are ignored

# The real contract library: 200+ real signed agreements from ~44 real
# counterparties. The FOLDER NAMES ALONE leak the counterparties, so no
# file-content scrub can make this publishable. Excluded wholesale.
docs/planning/

# CODEOWNERS routes review to GitHub TEAMS in the private origin org
# (@exos-legal/gc, @exos-legal/engineering). Those teams do not exist in the
# public org, so the file is BOTH non-functional there and the single most
# visible place the private org name would appear in the published tree.
# Excluded until the public org has real teams and a deliberate public
# CODEOWNERS is authored (issue #406).
.github/CODEOWNERS

# The manifest gate itself. It asserts that every pattern in THIS file matches
# a tracked path -- true in the private origin, and necessarily false in the
# cut, where those very paths have just been scrubbed. It is tooling for the
# repo that DOES the cutting, meaningless in the artifact the cut produces.
tests/lint-public-cut-exclude.py

overlay/
