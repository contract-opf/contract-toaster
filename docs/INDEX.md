Read this file first. Each line: `path` — one-sentence scope. anchors: heading-slugs. covers: code globs.
Jump to the exact section; do not scan the tree. Keeping this file true is part of
every change — the contract is [AGENTS.md](../AGENTS.md).

Four things are left out on purpose:

- The vendor kit at `frontend/vendor/orbit-diner/` is the designer's read-only
  source of record. Its docs are worth reading (start at its own `README.md`) but
  are never ours to edit or re-scope, so they are not indexed.
- The client corpus under `docs/planning/Internship-Agreement-Library/` has folder
  names that alone identify counterparties. Never index it, never quote it here.
- The bundle at `docs/planning/contract-toaster-review-packet.cat.md` is a
  disposable 2026-06 concatenation of docs that have since moved on. Read the
  originals instead.
- Both `overlay/README.md` and the root `aws-access-request.md` are excluded from
  the public cut.

`docs/planning/` itself is also cut wholesale, yet this index ships. **The public
cut must re-run `python3 tools/docs_sync.py project --write` after the scrub**, or
the shipped index will name paths that are not in it.
